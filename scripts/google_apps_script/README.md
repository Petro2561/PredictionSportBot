# Google Apps Script — счёт ЧМ-2026

Автоматически подставляет результаты **1-го тура** группового этапа в лист «Стадия 1».

## Источник данных

[football-data.org](https://www.football-data.org/) — бесплатный тариф, соревнование `WC`, сезон `2026`, `matchday=1` (24 матча).

## Установка

1. Откройте Google Таблицу → **Расширения** → **Apps Script**.
2. Создайте файл `wc2026_scores.gs` и вставьте код из репозитория.
3. Зарегистрируйтесь на https://www.football-data.org/client/register и скопируйте API Token.
4. В Apps Script выберите функцию `setApiToken`, в параметрах укажите токен, нажмите **Выполнить** (разрешите доступ).
5. Запустите `installTrigger()` один раз — обновление **каждые 5 минут**.
6. Проверка вручную: `updateWorldCupScores()`.

## Какие ячейки обновляются

| Матчи | Название | Счёт |
|-------|----------|------|
| 1–12  | B3:B14   | C, D |
| 13–24 | I3:I14   | J, K |

Обновляются только матчи со статусом `FINISHED`, `IN_PLAY` или `PAUSED` в API.

## Отключить

Запустите `uninstallTrigger()`.

## Если матч не находится

- Названия в таблице должны совпадать с ботом (русские или английские).
- Для 2-го тура измените в `CONFIG.API_URL` параметр `matchday=2`.
